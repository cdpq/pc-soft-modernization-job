# PC-Soft modernization

We rewrite programs originally built with **PC-Soft** (WinDev / WebDev, WLanguage) into a mainstream language. The usual target is **Python**. **C#** or **Go** may be used when they fit a case better.

The new program must perform the same task as the original one. You do this work together with our team.

## What a case includes

For each program, the reference material includes:

- the original source
- execution logs from a run of that program
- database snapshots taken before and after the run
- input files, when the program needs them

## What we are looking for

**Expected**

- You use an AI coding assistant in your daily work (Cursor, Claude Code, or an equivalent)
- Solid experience in web development
- Python
- SQL
- Microsoft SQL Server and SSMS

**Useful, not required**

- C#
- Go
- Angular or React
- PC-Soft WinDev / WebDev and WLanguage

Experience with the original environment is a plus. It is not required to do the work.
